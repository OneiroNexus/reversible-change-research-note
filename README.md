# The value of a reversible change

A method for measuring the complete human effort for an accepted, reversible change, with an illustrative cost calculation and a proposed matched-task study.

Research by Aaron Michael Weis. This paper-only edition presents a method and its limitations. [Read the paper](PAPER.md) · [Author ORCID](https://orcid.org/0009-0002-1906-148X)
